# AutoEcoar — Pacote do prólogo

Peça: **O presente: onde tudo começou a dar frutos**  
Formato: 16:9 horizontal · Duração estimada: 2–3 minutos · Narração proposta: voz feminina.

## Arquivos
- `01_Narracao.txt`: texto limpo para gravar ou gerar voz.
- `02_Roteiro_e_decupagem.md`: cenas, planos e orientação de edição.
- `03_Prompts_Google_Flow_EN.md`: prompts em inglês para os dois cenários de autorização.
- `04_YouTube.md`: título, descrição, capítulos e thumbnail.
- `05_Legendas_base.txt`: texto-base para sincronização.
- `06_Checklist_producao.md`: autorizações, gravação e publicação.

## Uso
Comece pela narração. Depois, obtenha as autorizações necessárias e grave ou gere as imagens. Ajuste tempos e capítulos à edição final.

**Privacidade:** não publique fotos, vídeos ou dados pessoais de Yuri sem o consentimento dele. Não inclua documentos clínicos, dados financeiros, endereço ou informações internas do local de trabalho. Imagens de IA devem ser identificadas como recriações ilustrativas.
